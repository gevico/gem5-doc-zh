# gem5 v25.0 支持的内核与磁盘镜像

本文档概述 gem5 v25.0 中使用内核与磁盘镜像组合、每种配置的支持程度，以及内核中包含的额外组件。

## 支持的体系结构

* X86
* ARM
* RISC-V

## 内核与磁盘镜像的配对

每个基础磁盘镜像使用以下内核版本：

* **Ubuntu 22.04 磁盘镜像**使用**内核 5.15**
* **Ubuntu 24.04 磁盘镜像**（包括 `npb` 和 `gapbs` 变体）使用**内核 6.8.12**

该配对在三种指令集架构（X86、ARM 和 RISC-V）中保持一致。

每个磁盘镜像都包含与其内核版本对应的内核模块（例如 24.04 镜像包含 6.8.12 内核的模块）。

## 内核是如何选定的

gem5 v25.0 中使用的内核版本与 Ubuntu 22.04（5.15）和 24.04（6.8.12）随附的默认版本一致。选择它们是为了在保持与各种工具兼容的同时，尽量减少定制维护开销。与 Ubuntu 的 LTS 发行版保持一致，可确保我们使用稳定、经过充分测试的内核，而无需定制补丁。

## 包含的内核模块

所有镜像都包含 `gem5-bridge` 内核模块，它使 m5 注解（例如 `m5_exit`、`m5_reset_stats`）可以在被模拟系统中无需 root 权限即可使用。该模块预装在磁盘镜像中，并与所含内核匹配。

## 磁盘镜像概览

| 磁盘镜像名称         | Ubuntu 版本    | 包含的基准测试       |
| -------------------- | -------------- | ------------------- |
| `ubuntu-22.04`       | 22.04          | 否                  |
| `ubuntu-24.04`       | 24.04          | 否                  |
| `ubuntu-24.04-npb`   | 24.04          | 是（NPB）           |
| `ubuntu-24.04-gapbs` | 24.04          | 是（GAPBS）         |

这些磁盘镜像可用于 X86、ARM 和 RISC-V。

## 支持状态

* 只有上面列出的组合（Ubuntu 22.04 配 5.15，以及 Ubuntu 24.04 配 6.8.12）在 gem5 v25.0 中**经过定期测试**并获得支持。
* 其他内核版本或配对**可能无法工作**，不保证与 gem5 v25.0 兼容。
