# MESI 两级（MESI Two Level）

### **协议概述**

  - 该协议建模**两级缓存层次结构**。L1 缓存
    对核心私有，而 L2 缓存由各核心共享。L1
    缓存分为指令缓存和数据缓存。
  - L1 与 L2 缓存之间维持**包含（Inclusion）**关系。
  - 在高层级上，该协议有四个稳定状态：**M**、**E**、
    **S** 和 **I**。处于 **M** 状态的块意味着该块可写
    （即具有独占权限）且已被弄脏（即它是
    片上唯一的有效副本）。**E** 状态表示一个具有
    独占权限（即可写）但尚未写入的缓存块。**S**
    状态意味着该缓存块只能读取，并且可能在多个私有缓存以及
    共享缓存中存在多个副本。**I** 意味着该缓存块无效。
  - 片上缓存一致性通过**目录
    一致性（Directory Coherence）**方案维护，其中目录信息与
    共享 L2 缓存中对应的缓存块放在一起。
  - 该协议有四类控制器 —— **L1 缓存控制器、
    L2 缓存控制器、目录控制器**和 **DMA 控制器**。
    L1 缓存控制器负责管理 L1 指令缓存和
    L1 数据缓存。L1 缓存控制器的实例数量
    等于被模拟系统中的核心数量。L2 缓存
    控制器负责管理共享 L2 缓存，并通过目录一致性
    方案维护片上数据的一致性。目录控制器充当通往内存
    控制器/片外主存的接口，并且还负责跨多个芯片的一致性
    以及来自 DMA 控制器
    的外部一致性请求。DMA 控制器负责满足一致性
    DMA 请求。
  - 该协议的主要优化之一是：如果 L1
    缓存请求一个数据块（即使只为读权限），L2 缓存
    控制器若发现没有其他核心持有该块，就会以独占权限返回该
    缓存块。这项优化是预期该缓存块很快会被
    同一个核心写入，从而通过该优化省去一次额外请求。**E**
    状态之所以存在正是出于这个原因（即当
    缓存块可写但尚未写入时）。
  - 该协议支持从
    私有 L1 缓存中*静默逐出（silent eviction）* *干净*
    缓存块。这意味着尚未被写入、且只有可读权限的缓存块
    可以在不通知 L2 缓存的情况下从私有 L1 缓存中丢弃。这项
    优化有助于减少发往 L2 缓存
    控制器的回写流量。

### **控制器说明**

### **L1 缓存
控制器**

| 状态              | 该状态的不变式与语义/用途                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **M**             | 该缓存块被**仅一个 L1 缓存**以独占状态持有。该块没有共享者。该数据可能是系统中唯一的有效副本。该缓存块的副本**可写**且**可读**。                                                                                                                                                                                                                                                                                                                                                                    |
| **E**             | 该缓存块被**恰好一个 L1 缓存**以独占权限持有。与 **M** 状态的区别在于该缓存块可写（也可读）但尚未写入。                                                                                                                                                                                                                                                                                                                                                                   |
| **S**             | 该缓存块被 1 个或多个 L1 缓存和/或 L2 缓存以共享状态持有。该块**只能读**。任何缓存都不能以独占权限持有该缓存块。                                                                                                                                                                                                                                                                                                                                                                               |
| **I / NP**        | 该缓存块无效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **IS**            | 瞬态。这意味着已为该缓存块发出 **GETS（读）**请求并正在等待响应。该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **IM**            | 瞬态。这意味着已为该缓存块发出 **GETX（写）**请求并正在等待响应。该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **SM**            | 瞬态。这意味着该缓存块原本处于 S 状态，随后发出了 **UPGRADE（写）**请求以获得该块的独占权限并正在等待响应。该缓存块**可读**。                                                                                                                                                                                                                                                                                                                                                                                          |
| **IS_I**         | 瞬态。这意味着在 IS 状态下该缓存控制器收到了来自 L2 缓存目录的失效。这发生在一种竞态条件下：其他核心正在写同一个缓存块，而本核心正试图为读而获取同一个缓存块。该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                   |
| **M_I**          | 瞬态。该状态表示缓存正试图从自己的缓存中替换一个处于 **M** 状态的缓存块，并且已向 L2 缓存目录发出回写（PUTX），正在等待回写确认。                                                                                                                                                                                                                                                                                                                                                                |
| **SINK_WB_ACK** | 瞬态。当在等待来自 L2 缓存目录的回写确认时，L1 缓存收到了干预（来自其他核心的转发请求），就会进入该状态。这表明已发出的回写与来自另一个缓存的请求之间发生了竞态。这也表明该回写输掉了竞态（即在它到达 L2 缓存目录之前，另一个核心的请求已到达 L2）。该状态对于避免在目录处静默丢弃回写时可能发生的复杂竞态至关重要。 |
|  |

### **L2 缓存控制器**

回顾一下，片上目录与 L2 缓存中对应的
缓存块放在一起。因此，L2 缓存块中的以下状态
编码了 L2 缓存中缓存块的状态与权限信息，
以及可能存在于一个或多个私有 L1 缓存中的该缓存块的一致性状态。除
一致性状态之外，每个缓存块还有两个更重要的字段，用于
做出正确的一致性动作。这些字段是
**Sharers** 字段，可以把它看作一个位向量，指示
哪些私有 L1 缓存可能持有给定的缓存块。
另一个重要字段是 **Owner** 字段，即在缓存块被
某个 L1 缓存以独占
权限持有时，该私有 L1 缓存的标识。

| 状态        | 该状态的不变式与语义/用途                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **NP**      | 该缓存块不在片上缓存层次结构中。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **SS**      | 该缓存块可能存在于多个私有缓存中，且仅为可读模式（即在私有缓存中处于 "S" 状态）。与该块对应的 "Sharers" 向量应给出可能在其缓存中持有该缓存块的私有缓存的标识。L2 缓存中的该缓存块有效且**可读**。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **M**       | 该缓存块**仅**存在于 L2 缓存中，并且具有独占权限。L1 缓存的读/写请求（GETS/GETX）可以直接由该 L2 缓存满足。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **MT**      | 该缓存块以独占权限存在于**某个**私有 L1 缓存中。L2 缓存中的数据可能是过期数据。持有该块的 L1 缓存的身份可以在与该缓存块关联的 "Owner" 字段中找到。来自其他核心/私有 L1 缓存的任何读/写请求（GETS/GETX）都需要转发给该缓存块的所有者。L2 无法自行服务请求。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **M_I**    | 瞬态。该状态表示缓存正试图从自己的缓存中替换该缓存块，并已向目录控制器（它充当通往主存的接口）发出回写（PUTX/PUTS），正在等待回写确认。该数据既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **MT_I**   | 瞬态。该状态表示缓存正试图从自己的缓存中替换一个处于 **MT** 状态的缓存块。已向该缓存块的当前所有者（私有 L1 缓存）发出失效，并正在等待来自所有者 L1 缓存的回写。注意这次失效（称为反向失效，back-invalidation）对于确保 L1 与 L2 缓存之间维持包含关系至关重要。该数据既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **MCT_I**  | 瞬态。该状态与 **MT_I** 相同，只是已知 L2 缓存中的数据处于*干净*状态。该数据既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **I_I**    | 瞬态。L2 缓存正试图替换一个处于 **SS** 状态的缓存块，且 L2 中的该缓存块处于*干净*状态。已向该缓存块的所有可能共享者（L1 缓存）发出失效。L2 缓存的目录正在等待来自各 L1 缓存的所有必需确认到达。注意这次失效（称为反向失效，back-invalidation）对于确保 L1 与 L2 缓存之间维持包含关系至关重要。该数据既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **S_I**    | 瞬态。与 **I_I** 相同，只是 L2 缓存中该缓存块的数据是*脏*的。这意味着与 **I_I** 的情况不同，该数据需要被发送到主存。该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **ISS**     | 瞬态。L2 收到了来自某个私有 L1 缓存的对一个片上缓存中不存在的缓存块的 **GETS（读）**请求。已向主存（目录控制器）发出读请求，并正在等待来自内存的响应。只有在该请求针对数据缓存块（而非指令缓存块）时才会进入该状态。该状态的用途是：如果发现只有一个 L1 缓存请求了该缓存块，就把该块以独占权限返回给请求者（尽管它请求的是读权限）。该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **IS**      | 瞬态。该状态与 **ISS** 类似，只是如果所请求的缓存块是指令缓存块，或者在等待来自内存的响应期间有多个核心请求同一个缓存块，则会进入该状态而不是 **ISS**。一旦所请求的缓存块从主存到达，该块就会以只读权限发送给请求者。该状态下该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **IM**      | 瞬态。当 L2 缓存收到针对片上缓存层次结构中不存在的缓存块的 L1 GETX（写）请求时，会进入该状态。已向主存发出以独占模式获取该缓存块的请求，但响应尚未到达。该状态下该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **SS_MB**  | 瞬态。一般而言，名称以 "B" 结尾的任何状态（如本状态）也意味着它是一个*阻塞*一致性状态。这意味着目录正在等待来自私有 L1 缓存的某些响应，并且在收到所需响应之前不会处理任何其他请求（即请求实际上被串行化）。当某个 L1 缓存以独占权限请求某个缓存块（即 GETX 或 UPGRADE）而该缓存块的一致性状态为 **SS** 时，就会进入该特定状态。这意味着所请求的缓存块可能在私有 L1 缓存中拥有可读副本。因此在把独占权限授予请求者之前，必须使 L1 缓存中所有可读副本失效。该状态表示已向可能的共享者（L1 缓存）发出所需的失效，并且已告知请求者：在它获得该缓存块的独占权限之前需要收到多少个失效确认。一旦请求者 L1 缓存收到所需数量的失效确认，它就会通过 *UNBLOCK* 消息告知目录，从而让目录脱离该阻塞一致性状态，之后就可以恢复处理该缓存块的其他请求。该状态下该缓存块既不可读也不可写。 |
| **MT_MB**  | 瞬态，同时也是*阻塞*状态。当 L2 缓存的目录已向某个请求者 L1 缓存发出具有独占权限的缓存块，但尚未收到该请求者 L1 缓存确认收到独占权限的 *UNBLOCK* 时，就会进入该状态。该状态下该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **MT_IIB** | 瞬态，同时也是*阻塞*状态。当收到对一个当前被另一个私有 L1 缓存以独占权限持有的缓存块（即目录状态为 **MT**）的读请求（GETS）时，就会进入该状态。对于这类请求，L2 缓存的目录会把请求转发给当前所有者的 L1 缓存并转换到该状态。在该缓存块可以被解除阻塞（从而开始处理针对它的后续请求）之前，需要发生两个事件：当前持有该缓存块的所有者需要向 L2 缓存发送回写，以用最新值更新 L2 的副本；请求者 L1 缓存也需要向 L2 缓存发送 *UNBLOCK*，表明它已获得具有所需一致性权限的所请求缓存块。在 L2 缓存中该状态下该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **MT_IB**  | 瞬态，同时也是*阻塞*状态。当处于 **MT_IIB** 状态时，L2 缓存控制器收到了来自请求者 L1 缓存的 *UNBLOCK*，但尚未收到来自该块先前所有者 L1 缓存的回写，就会进入该状态。在 L2 缓存中该状态下该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **MT_SB**  | 瞬态，同时也是*阻塞*状态。当处于 **MT_IIB** 状态时，L2 缓存控制器收到了来自该块先前所有者 L1 缓存的回写，而尚未收到来自当前请求者对该缓存块的 *UNBLOCK*，就会进入该状态。在 L2 缓存中该状态下该缓存块既不可读也不可写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
