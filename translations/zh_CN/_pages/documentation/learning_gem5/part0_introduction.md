# 引言

本文档的目标是让你全面了解如何使用 gem5 以及 gem5 代码库。本文档的目的不是详细描述 gem5 的每一个特性。读完本文档后，你应当能够自如地在课堂和计算机体系结构研究中使用 gem5。此外，你应当能够修改和扩展 gem5，并把你的改进贡献到 gem5 主仓库。

本文档带有我个人过去六年在威斯康星大学麦迪逊分校读研究生期间使用 gem5 的经验色彩。文中给出的示例只是做法之一。与 Python 的箴言“应当有一种——最好只有一种——显而易见的方式来做这件事。”（出自 The Zen of Python。见：
[The Zen of Python](https://www.python.org/dev/peps/pep-0020/#the-zen-of-python){:target="_blank"}）不同，在 gem5 中做同一件事有许多不同的方式。因此，本书给出的许多示例都是我眼中最好的做法。

我（在吃过苦头之后）学到的一个重要教训是：使用 gem5 这样复杂的工具时，重要的是在真正使用它之前理解它的工作方式。

本书的源码可以在
<https://github.com/gem5/website/tree/stable/_pages/documentation/learning_gem5/> 找到。

## gem5 是什么？

gem5 是一个模块化的离散事件驱动计算机系统模拟（simulation）平台。这意味着：

1. gem5 的组件可以方便地重新排列、参数化、扩展或替换，以满足你的需求。
2. 它把时间的流逝模拟为一系列离散事件。
3. 它的预期用途是以多种方式模拟一个或多个计算机系统。
4. 它不只是一个模拟器，而是一个模拟器平台，让你可以按需使用其中任意多的现成组件来搭建自己的模拟系统。

gem5 主要用 C++ 和 python 编写，大多数组件以 BSD 风格许可提供。
它可以在全系统（full-system）模式（FS 模式）下模拟带设备和操作系统的完整系统，也可以在系统调用模拟（syscall emulation）模式（SE 模式）下模拟仅用户空间的程序，此时系统服务由模拟器直接提供。
在 CPU 模型上对执行 Alpha、ARM、MIPS、Power、SPARC、RISC-V 和 64 位 x86 二进制程序的支持程度各不相同，这些 CPU 模型包括两个简单的单 CPI 模型、一个乱序模型和一个顺序流水线模型。
内存系统可以灵活地用缓存与交叉开关搭建，也可以使用提供更灵活内存系统建模能力的 Ruby 模拟器。

这里没有提及的组件和特性还有很多，但仅从这份不完整的清单就应能看出，gem5 是一个精密且能力强大的模拟平台。
即便 gem5 今天已经能做这么多，在个人和一些公司的支持下，它仍在持续开发，新特性不断加入，既有特性也定期改进。

## 开箱即用的能力
gem5 是为计算机体系结构研究而设计的，但如果你要研究全新的、新颖的东西，它很可能无法开箱即用地评估你的想法。如果它能，那大概意味着已经有人评估过类似想法并发表了成果。

要充分发挥 gem5 的价值，你很可能需要针对项目目标添加新能力。gem5 的模块化设计应当能帮助你做出修改，而无需理解模拟器的每个部分。

当你添加所需的新特性时，请考虑把改动回馈给 gem5。这样他人就能受益于你的辛勤工作，gem5 也能成为更好的模拟器。
